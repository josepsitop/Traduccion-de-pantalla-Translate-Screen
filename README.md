# BubbleLens

Burbuja flotante que traduce sin internet (OCR + traducción en el dispositivo).

**Dos modos**
- **Pantalla (tocar):** tocas la burbuja y traduce todo lo que ves, dibujado sobre el texto original. Tócala otra vez para quitarlo.
- **Diálogo (auto):** eliges la región del cuadro de texto del juego y traduce sola cada vez que el texto cambia.

## Compilar con GitHub
1. Crea un repositorio y sube **todo el contenido** de esta carpeta (incluida `.github` y `app/release.jks`).
2. Pestaña **Actions → Build APK → Run workflow** (o se ejecuta solo al subir).
3. Cuando termine (≈ 5–8 min), entra a la ejecución y descarga **BubbleLens-APK** (zip con el `.apk`).
4. Instala el APK en un teléfono Android 8 o superior (64 bits).

## Primer uso
1. Abre la app, elige idioma del juego y «Traducir a», toca **Descargar** (una vez, con internet).
2. **Iniciar burbuja** → concede «Mostrar sobre otras apps» y la captura de pantalla.
3. Mantén pulsada la burbuja para cambiar de modo, de idioma, ajustar la región o cerrarla.
